# Plan Pilot 前端与体验方向：平静工作台

> 2026-11-10 第一轮体验评审结论。目标不是增加装饰，而是让每次点击都可预测、可反馈、可撤销，让「现在该做什么」始终比工具本身更醒目。

## 为什么选择这个方向

Plan Pilot 的差异化不是聊天框，也不是又一张高密度日历，而是把目标、任务、固定安排和当天执行连起来。因此保留现有闭环：

- **当下**：回答现在该做什么，完成或进入专注；
- **今日**：快速收集、明确约束、预览并排期；
- **目标**：把长期方向拆成下一步；
- **复盘**：收束当天，处理未完成与明日重点。

视觉延续暖中性底、单一强调色、细分隔线和中文排版。高级感来自内容优先级、留白、字阶和一致反馈，而不是再增加主题、渐变、阴影或卡片层数。

三个候选方向中，本方案为 A；另外两条路线可以以后局部吸收：

| 方向 | 核心模型 | 结论 |
|---|---|---|
| A. 平静工作台 | 规划与执行分工，本地能力完整，AI 显式辅助 | 当前采用，改动可控且不依赖 Key |
| B. 引导式规划教练 | 对话和分步向导为主，计划草稿为辅 | 可嵌入晨间与目标拆解，不让整个产品变成聊天壳 |
| C. 专业时间地图 | 周日历、甘特、拖拽和键盘效率为中心 | 可作为高级视图，暂不做全站重构 |

## 已落地的第一波

- OmniBar 在提交前展示回车结果；带明确日期/时长信号的任务可本地添加，弱输入交给 AI，✨ 始终是显式 AI 入口。
- AI 禁用、无 Key 等错误会展开到可见的访谈面板；AI 建议支持逐条拒绝。
- 「当下」区分固定占用、已完成、下一件事和当日时间块结束；日期切换只属于今日与复盘。
- 复盘按日期载入已有内容；批量顺延前说明影响，只移动未完成任务及其关联块，不误删固定安排。
- 移动设置改为全宽/近全宽单列并覆盖底部导航；底部导航增加文字标签。
- 触屏时间块表面允许纵向滚动，精确编辑走明确按钮；桌面拖拽保留。
- 晨间卡不再重复顶栏大日期，精力状态不再给日期着色。

## 第二波：内容优先级与安全性

1. 将今日四项同权统计收成一条容量摘要，超载时提供「处理未排 / 重新安排」动作；当前与下一时间块提升到时间轴标题区。
2. 目标页改为内容优先：目标与甘特在前，新增和拆解默认折叠；后续任务可直接跳转到对应日期安排。
3. 将自动排期已有的「预览 → 确认 → 撤销」范式推广到任务、块、目标删除；优先轻量撤销，不连续弹确认框。
4. AI 访谈关闭时保留未接受建议，或明确提示草稿将丢弃；按日期/范围形成可恢复的规划草稿箱。
5. 设置按「基础 / 周期 / AI 与语音 / 数据」分路，补充对话框焦点圈定和焦点恢复。

## 第三波：高级计划与复盘

- 排期预览升级为时间轴上的新旧 diff，标出新增、移动、未排和冲突，允许逐项接受。
- 目标工作区支持选中目标、详情、关联任务与甘特联动；移动端提供列表/甘特双模式。
- 复盘自动汇总计划与实际，支持选择性顺延、明日重点一键转任务和历史复盘。
- 增加周日历作为高级视图，不牺牲移动端的「当下」简单性。

## 验收基线

每次体验改动至少走查以下任务，而不是只看截图：

1. 无 Key 快速添加「写周报 30 分钟」，弱输入不会静默建任务；
2. 排一个会议、预览排期、拒绝一条 AI 建议；
3. 在 390px 触屏视口滚动时间轴、编辑时间块、打开设置；
4. 在今日、当下、目标、复盘之间切换，日期语义保持明确；
5. 切换日期后复盘不串稿，批量顺延不删除固定安排。

建议视口：320 / 390 / 820 / 1100 / 1440px。截图需覆盖默认今日、AI 对话、排期预览、复盘、设置和移动状态，并与当前代码版本同步。
